# RaceDay – Event Management System

## System Description

RaceDay is a web-based event management system designed for the South African road running, walking and cycling community. The system allows event organisers to create and manage events, categories, routes and results, while participants can browse events, enter available categories and track their performance.

The system is designed to provide a centralised platform for managing event information, participant enrolments, race results and supporting information such as route and weather data.

## User Roles

### Event Organiser
Event organisers can create and manage events, manage event categories, provide route information and manage participant results.

### Participant
Participants can browse available events, register for event categories and view their race performance and results.

### Administrator
The administrator manages the overall system, including users, event information and system data.

## Database

The RaceDay database contains the following main entities:

- RaceDayUsers
- Events
- Categories
- Enrolments
- Results
- Routes
- Weather

The database structure and relationships are documented in the ERD and SQL scripts provided in this repository.
